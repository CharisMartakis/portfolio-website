  • Interactive gameplay and user experience

Oh My Savior — Details

A personal Chrome extension acting as a cloud-synced personal library. Built with WXT (a modern MV3 extension framework) and React, with Supabase for auth, database, and storage.

  • Technologies: TypeScript, React, WXT (MV3), Supabase, dnd-kit, Tiptap
  • YT Saver: save YouTube videos with thumbnails
  • PG Saver: save any web page with screenshot
  • NT Saver: rich-text notes with Tiptap editor
  • Drag-and-drop reordering, categories, real-time sync across devices
  • Trash with 7-day auto-purge for soft-deleted items
