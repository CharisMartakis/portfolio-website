## What this version contains

Version 0.1 was built entirely with handwritten HTML and CSS — no frameworks. The focus was on learning core layout techniques from scratch.

**Projects built in this version (in order):**
1. Basic site scaffold — `index.html`, `style.css`, initial `resume.html`
2. Replaced "About" page with a proper CV-style `resume.html`
3. **Greek Flag** — pure CSS recreation using CSS Grid
4. **Pricing Table** — responsive layout using CSS Flexbox
5. **Piet Mondrian Painting** — CSS Grid composition and layout
6. **E-shop with Bootstrap** — first Bootstrap-heavy project (course exercise)

**Key CSS techniques practiced:** Box model, Flexbox layouts, CSS Grid, custom properties, hover transitions, responsive design without a framework.
