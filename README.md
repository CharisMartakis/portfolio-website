## What this version contains

Version 0.2 was a complete redesign of the entire site using **Bootstrap 5.3**. Every page was rebuilt or heavily refactored. This is when the site started looking professional and the design became consistent.

**What changed vs Version 0.1:**
- `style.css` fully rewritten — removed old manual CSS, rebuilt cleanly around Bootstrap utilities with custom overrides
- `index.html` rebuilt with Bootstrap grid: hero section, about, projects preview, contact teaser
- `resume.html` redesigned with sticky sidebar (skills cards) + main content column layout
- `projects.html` rebuilt with Bootstrap card grid and modals for each project
- `contact.html` created — full contact form UI (name, email, subject, message)
- Screenshot thumbnails added for all projects (used as card images)
- Profile photo, doge meme image, GitHub/LinkedIn SVG icons added
- Old Misc projects (`birthday-invite.html`, `motivational-quote.html`) removed from public pages
- Site published via GitHub Pages

**Key Bootstrap techniques practiced:** Grid system, Flexbox utilities, Cards, Modals, Navbar with collapse, responsive breakpoints (col-12 / col-md-6 / col-lg-4).
